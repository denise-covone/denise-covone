### 2. Progetto Python
* **Descrizione:** Uno script di Natural Language Processing (NLP) volto all'analisi stilistica e computazionale di testi letterari. Il programma estrae, isola e confronta la frequenza relativa degli aggettivi riferiti alle figure femminili (tramite nomi comuni e propri) nelle opere di Giovanni Verga (*La Lupa*) e Luigi Pirandello (*L'Esclusa*). Utilizza tecniche avanzate di *dependency parsing* e scomposizione in sintagmi nominali, generando infine grafici statistici comparativi.
* **Tecnologie usate:** Python, Spacy (`it_core_news_lg`), Matplotlib, Collections (Counter)
* **📂 [Vedi il codice del progetto Python](https://github.com)**
